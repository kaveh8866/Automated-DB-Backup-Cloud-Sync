7. Failures met and fixed on the way
------------------------------------
    a) rclone "can not create client, bad configuration: did not find a proper
       configuration for tenancy"
       cause: rclone's OCI backend expects provider = user_principal_auth with a
       config_file profile; provider = user is not a known token, so no auth
       resolution happened at all.
       fix:   native backend config with config_file/config_profile as above.

    b) "missing rclone config at /etc/rclone/rclone.conf" followed by
       "Failed to load config file: permission denied"
       cause: the bind mount is read-only but not ownership-mapped. The runner
       runs as uid 100/101; configs written by ubuntu at mode 400 are unreadable
       inside the container. No sudo is available on this host for the
       deployment user, so chown was not an option.
       fix:   chmod 444 on rclone.conf, oci_config and oci_api_key.pem. The mount
       is read-only, the host is single-tenant, and no other login user exists.
