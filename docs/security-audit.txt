--- 2. tracked-content scan ----------------------------------------------
Patterns: OpenAI-style sk-*, AWS AKIA*, PEM private-key headers, GitHub
gh[pousr]_*/github_pat_*, Google AIza*, Slack xox*-, and realistic OCI OCIDs
(ocid1.<type>.<realm>.<16+ chars>).

  $ git grep -n -i -E 'sk-[A-Za-z0-9]{16,}|AKIA[0-9A-Z]{16}|BEGIN [A-Z ]*PRIVATE KEY|...' -- .
  clean (no key material)

  $ git grep -n -i -E '(password|secret|token|access_key)\s*[:=]\s*[A-Za-z0-9!@#$%^&*_-]{8,}' -- . ':!*.example' ':!docs/*'
  docker/docker-compose.yml:52   POSTGRES_PASSWORD: ${POSTGRES_PASSWORD:-change-me-before-exposing}
  docker/docker-compose.yml:96   PGPASSWORD: ${POSTGRES_PASSWORD:-change-me-before-exposing}

The two compose hits are Compose guard defaults (the value only applies when the
variable is unset, and the string itself is an instruction, not a secret). They
are intentional: a container that starts with an obvious placeholder is safer
than one that starts with an empty password.

Finding fixed in this stage: AGENT_GUIDE.md carried a literal
`POSTGRES_PASSWORD=drill-only-password` inside a sed example. It was a throwaway
string, but it normalises pasting passwords into documentation, so it now reads
`$(openssl rand -hex 16)`.

The file must contain only KEY=value lines and comments; a header or prose line
would break both the scanner and `docker compose --env-file`.

--- 6. limits of this audit ---------------------------------------------
This is a pattern- and rules-based audit, not a credential-history rewrite. It
cannot prove that a secret was never committed on a branch that has since been
force-pushed, and it performs no entropy analysis over binaries. Here the
history is small and single-author (one placeholder commit plus the delivery
commits), and `git log --all --diff-filter=A --name-only` lists every path ever
added: 38 files at audit time, all of them documentation, scripts, IaC, configs
or examples. No key, dump, archive or state file appears anywhere in it.

Recommendation for any fork: run `gitleaks detect --no-git` before the first
push, and again with `--log-opts=--all` when the history is shared.
